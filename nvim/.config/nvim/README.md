# README

>I add here random things I don't want to forget

- Where does lazy install to? Run :Lazy and then just press enter on any plugin => /home/daniel/.local/share/nvim/lazy/yolo.nvim
- Run :Lazy and press u when hovered over plugin to update only this plugin => i.e., check on yolo.nvim => updates whenever the main branch updates!
- dev plugins are loaded with lazy.nvim => see lua/plugins/nvim_plugins.lua
- autocmd = "Buffer local event listener"
- :help ins-completion (auto-completion defaults)
- Hover over keyword and then press shift+kk (twice the k) to trigger and move into preview!
- Use ctrl+W+H (or J, K, L) to arrange splits.
- Use ctrl+= to make splits equal size.
